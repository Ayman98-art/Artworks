# مِرآة // MIRROR ARCHIVE - Cybernetic Art Gallery

أرشيف فني وتاريخي بتصميم مستقبلي وخيال علمي (Sci-Fi / HUD)، يوثق **60 لوحة فنية خالدة** مع نظام توقيع صوتي تفاعلي، محلل طيف ترددي، وسرد صوتي ذكي.

## 🚀 المميزات المنجزة:
1. **60 لوحة فنية كاملة**: مع بيانات دقيقة وتفصيلية (الاسم بالعربي والإنجليزي، الفنان، السنة، العصر الفني، مكان الحفظ، التردد الصوتي، الوصف والتحليل الفلسفي).
2. **تصميم Sci-Fi / HUD داكن احترافي**:
   - استخدام خطوط `Cairo` للنصوص العربية و `Orbitron` و `Share Tech Mono` للبيانات الرقمية والمؤشرات.
   - تأثيرات نيون (Cyan / Purple / Magenta)، شبكة كوزمية، وتأثير المسح الضوئي (Scanlines).
   - بطاقات هولوغرافية بحواف زجاجية وتأثير تكبير وتوجيه إلكتروني.
3. **حل مشكلة الصور نهائياً**:
   - استخدام روابط مباشرة مع تفعيل `referrerpolicy="no-referrer"` لمنع حظر Hotlink من ويكيبيديا أو مزودي الخدمة.
   - وجود رابط بديل فوري (Backup CDN via weserv.nl) في حال تعذر تحميل الصورة الأصلية.
   - نظام توليد هولوغرام إجرائي عبر HTML5 Canvas تلقائياً في حال فشل الاتصال، بحيث لا تظهر أي بطاقة مكسورة إطلاقاً.
4. **التوقيع الصوتي (Voice Signature)**:
   - مولد صوتي تركيبي (Web Audio API Synthesizer) يولد موجات صوتية وهارمونيات ترددية مخصصة لكل لوحة بناءً على عصرها الفني.
   - محلل طيف بصري (Real-time Canvas Audio Visualizer) يتحرك نبضياً مع الصوت.
   - نظام السرد الصوتي بالذكاء الاصطناعي (Web Speech API) لقراءة التحليل الفني بالصوت.
   - مؤثرات صوتية مستقبلية للواجهة (UI Bleeps & Sweeps) مع نغمة خلفية سيبرانية خافتة (Cyber Drone).
5. **فلترة وبحث فائق السرعة**:
   - بحث فوري بالاسم، الفنان، العصر، أو الكلمات المفتاحية.
   - فلترة حسب العصور الفنية وقائمة منسدلة لكافة الفنانين.
   - خيارات ترتيب متقدمة (الأقدم، الأحدث، أبجدياً).
   - عدّاد حي محدث (مثال: `عرض 60 / 60 لوحة`).
